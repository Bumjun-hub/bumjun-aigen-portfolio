PERSONAL PROJECT · 2026

Project S

사용자 실측 기반 의류 사이즈 추천 서비스

Next.js TypeScript Spring Boot PostgreSQL JWT
문제 발견

브랜드마다 다른 의류 실측 기준으로 인해 온라인 쇼핑에서 적절한 사이즈를 선택하기 어렵다는 문제에 주목했습니다.

해결을 위한 시도

사용자의 신체 정보와 평소 잘 맞는 옷의 실측·착용감 정보를 활용해 상품 사이즈를 비교하는 규칙 기반 추천 기능을 설계하고 구현했습니다.

직접 기여한 부분

Next.js와 Spring Boot 기반 서비스를 단독 설계·개발했습니다. 회원 인증, REST API, 추천 계산 로직, 상태 관리, 데이터베이스 연동을 구현했습니다. 추천 계산 책임을 RecommendationCalculator로 분리해 수정과 검증이 쉽도록 구성했습니다.

결과와 배운 점

주요 기능의 단위·통합 테스트 70건을 작성하고, Ubuntu Server에서 직접 배포를 경험했습니다. 기능 구현뿐 아니라 시스템 구조와 데이터 일관성을 고려하는 중요성을 배웠습니다.

TEAM PROJECT · 4 MEMBERS · 2025

NeighFund

지역 주민 참여형 제안·펀딩 플랫폼

React JavaScript Spring Boot MySQL Context API
문제 발견

지역 주민들이 문제를 제안하고 함께 해결 과정에 참여할 수 있는 서비스를 만들고자 했습니다.

팀 프로젝트에서의 역할

프론트엔드 개발에 참여해 제안 게시판, 펀딩 관련 UI, 검색·정렬·무한스크롤, 다단계 펀딩 작성 흐름 등을 구현했습니다. Context API를 사용해 단계 이동 중 입력 데이터가 유지되도록 구성했습니다.

이후 발견한 문제

기능 개발 이후 페이지별로 분산된 API 호출과 일관되지 않은 상태 관리 구조가 유지보수에 불리하다는 점을 발견했습니다.

새로운 개선 시도

이후 개인 리팩터링을 진행하며 API 호출을 공통 모듈로 재구성하고 React Query를 도입했습니다. 서버 상태와 UI 상태의 책임을 분리하고 컴포넌트 구조를 개선했습니다.
